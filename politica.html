Política de Privacidade

Última atualização: 07 de abril de 2026

1. Informações Gerais

A Calculadora Simples é um utilitário matemático. Esta política descreve como tratamos as informações dos usuários.

2. Coleta de Dados

  • Dados Pessoais: O Aplicativo não coleta, armazena ou solicita dados de identificação pessoal direta.
  • Dados de Uso: Utilizamos o SDK do Google AdMob que pode coletar identificadores técnicos (como ID de publicidade) para fins de anúncios.

3. Finalidade e Segurança

Os dados técnicos são usados exclusivamente para exibição de anúncios relevantes. Operamos de forma serverless, sem banco de dados externo.

4. Consentimento

Ao utilizar o Aplicativo, o usuário concorda com os termos aqui descritos e com o processamento de anúncios pelo Google.
